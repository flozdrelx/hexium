# Hexium Browser Prototype V0.02

#### Experimental mini browser project

A CLI-based browser prototype currently in development.

---

# Current Features

* CLI interface
* Website downloading support
* Export websites as:
  * Markdown (`.md`)
  * HTML (`.html`)
  * Both formats

---

# Websites Folder

Downloaded websites are stored in:

```text
Scripts/websites
```

# Current Status

The prototype is currently stable and working properly.
